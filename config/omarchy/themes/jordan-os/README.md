# Jordan OS

Cabinet desktop on Omarchy. XP is a costume, not the product name.

Start opens a jukebox cabinet: sleeve / now-playing, night-shift (collapses
when empty), Elon (collapses when empty). Footer keys switch eras:

| Era | Chrome |
|---|---|
| **Mac** | Aqua, menu bar top, candy stripe, traffic lights |
| **95** | Chicago gray, bottom bar, square Start, 3D bevel |
| **XP** | Luna pill, Bliss, floating gadgets, dark table |
| **DOS** | Norton/MC two-pane, no landscape |

Display Properties: room (Bliss / Dirt / Gold / Night / Soundtrack),
don’t-paint, gaps, shadows, per-era remembered bar layout.

```
jordan-os                         # show options
jordan-os era mac|95|xp|dos
jordan-os room bliss|dirt|gold|night|soundtrack
jordan-os dont_paint on|off
jordan-os gaps tight|classic|room
jordan-os shadows on|off
jordan-os bar top|bottom|left|right
```

Unlock copy: **Biker, not cyclist**. Face-line screensaver is unchanged.

`Super+Ctrl+J` toggles Start.
