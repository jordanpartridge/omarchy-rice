# Jordan XP

Retro Windows XP Luna on Omarchy, built around Jordan Partridge: Mesa AZ,
biker (not cyclist), Laravel / terminal maximalist, the Asgard fleet
(Thor, Loki, Odin), GitHub orgs (`the-shit`, `conduit-ui`, `synapse-sentinel`,
`PSTrax`, `PartridgeRocks`), Elden Ring, Red Dead Redemption 2, and
the-shit/music.

The bar is a high-contrast teal-navy taskbar (off Microsoft Luna: cactus
Start, oasis teal accents, paper menus at WCAG AAA). The **start** button
on the left opens a
two-pane Start menu (programs, orgs, fleet, games, hobbies) plus **Display
Properties** for live tweaks.

## Tweaks

From the Start menu → Display Properties, or:

```
jordan-xp                         # show options
jordan-xp variant luna|olive|silver|mesa|erdtree
jordan-xp gaps tight|classic|room
jordan-xp border thin|luna|chunky
jordan-xp shadows on|off
jordan-xp chrome xp|mixed|dark
jordan-xp start classic|bright|gold
```

| Option | What it does |
|---|---|
| **variant** | Pacific teal (default, not Luna), Olive, Silver, Mesa, Erdtree |
| **gaps** | Window gaps (XP-tight, classic, or roomy) |
| **border** | Title-bar-like Luna border thickness |
| **shadows** | XP-style drop shadows on windows |
| **chrome** | Beige XP menus, mixed (blue bar + dark menus), or all-dark |
| **start** | Classic green, bright green, or Erdtree gold Start button |

## Different from stock Omarchy

- Bottom Luna taskbar with a green Start pill (not just a recolor)
- Start menu for orgs / fleet / Steam games instead of only the Omarchy menu
- Display Properties panel that rewrites this theme and re-applies it
- Square windows, Luna blue title-bar gradient borders, optional drop shadows

`Super+Ctrl+J` toggles Start. Left-click the green button; right-click opens
Display Properties.
