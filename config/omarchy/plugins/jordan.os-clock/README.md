# Jordan OS clock

Wide floating desktop gadget. Skins follow the cabinet era (Mac / 95 / XP / DOS).

| Input | Action |
|---|---|
| Drag | Move |
| Double-click | Snap to bottom-right |
| Right-click | Cycle corners |
| Middle-click | Toggle always-on-top |
| Start → Clock | Show / hide |
| Super+Ctrl+U | Show / hide |

Position is saved to `~/.local/state/omarchy/jordan-os-clock.json`.
