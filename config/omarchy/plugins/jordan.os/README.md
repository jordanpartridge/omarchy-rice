# Jordan OS Start

Cabinet homepage for the `jordan-os` Omarchy theme.

| Input | Action |
|---|---|
| Left click | Toggle cabinet |
| Right click | Display Properties |
| Middle click | Omarchy root menu |
| Super+Ctrl+J | Toggle Start |
| Escape | Close |
| Backspace | Back one page |
| Footer keys | Mac · 95 · XP · DOS (layout + chrome; packets stay) |

Homepage slips: sleeve / now-playing, night-shift (collapses empty), Elon (collapses empty).
Museum (orgs, fleet, games, hobbies) is off the homepage.
Display Properties: room, don’t-paint, gaps, shadows, per-era bar layout.
