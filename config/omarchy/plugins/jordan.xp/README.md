# Jordan XP Start

Green Start button for the `jordan-xp` Omarchy theme.

| Input | Action |
|---|---|
| Left click | Toggle Start menu |
| Right click | Display Properties |
| Middle click | Omarchy root menu |
| Super+Ctrl+J | Toggle Start |
| Escape | Close |
| Backspace | Back one page |

Pinned: terminal, browser, files, GitHub, Grok, music.
Folders: orgs, fleet (Thor / Loki / Odin), games (Elden Ring, RDR2, bikes),
hobbies (bike, music, LEGO, homelab).
Display Properties writes `~/.config/omarchy/themes/jordan-xp/options.json`
and runs `apply.sh`.
