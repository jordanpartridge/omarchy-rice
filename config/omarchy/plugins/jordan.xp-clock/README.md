# Jordan XP clock

Wide floating desktop gadget. Floats above windows, like a Vista sidebar
gadget. Drag it; it is not on the taskbar.

| Input | Action |
|---|---|
| Drag | Move |
| Double-click | Snap to bottom-right (XP tray corner) |
| Right-click | Cycle corners |
| Middle-click | Toggle always-on-top |
| Start → Clock | Show / hide |
| Super+Ctrl+U | Show / hide |

Position is saved to `~/.local/state/omarchy/jordan-xp-clock.json`.
